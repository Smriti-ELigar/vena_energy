# Renewable Energy Monitoring System - Vena Energy Internship  

This repository showcases the projects and assignments I worked on during my internship at **Vena Energy**, where I contributed to enhancing renewable energy monitoring systems through innovative user interfaces and real-time data visualizations.  

## Projects and Contributions  

### 1. **User Management Interface**  
- Designed and implemented a comprehensive user management system.  
- Included features for managing roles and permissions to streamline operations.  
- Improved system efficiency by simplifying administrative workflows.  

### 2. **Real-Time Data Visualization**  
- Visualized wind turbine performance using canvas elements.  
- Dynamically colored turbine parts based on real-time wind speed and active power data.  
- Enhanced performance monitoring by reducing data processing time and improving responsiveness.  

### 3. **KPI Monitoring and Platform Reliability**  
- Integrated real-time progress bars to effectively display turbine performance metrics.  
- Improved KPI monitoring for better reliability and data accuracy.  
- Calculated and visualized the Plant Load Factor (PLF) to enhance system performance insights.  

## Key Features  

- **Dynamic Visualization**: Real-time coloring of turbine parts to reflect performance metrics.  
- **Efficiency Boost**: Optimized data processing time and system reliability.  
- **User Management**: Role-based access control for enhanced security and usability.  

## Technologies Used  

- **Frontend**: HTML, CSS, JavaScript (Canvas API)  

## Outcomes  

- Enhanced system efficiency by streamlining user management and improving data visualization.  
- Reduced data processing time, enabling quicker decision-making.  
- Increased platform reliability through accurate KPI monitoring.
